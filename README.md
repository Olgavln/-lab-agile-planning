# -lab-agile-planning

## Project Description

This project was created as part of a course on project planning and management using the Agile methodology. It explores the process of sprint planning, task allocation, and risk assessment for successful project delivery. This project also incorporates knowledge gained from Coursera courses on Agile and Project Management.

## Project Goals

- Study and apply the Agile methodology in real-world scenarios.
- Develop and implement sprints to complete tasks.
- Manage risks, resources, and time.
- Create documentation for planning and task execution.

## Methodology

The project uses the Agile methodology for task management and planning:
- The project is divided into sprints (short working cycles, typically 2 weeks).
- Kanban boards are used for task management.
- Each task is in one of the following statuses: "To Do", "In Progress", or "Done".
- Daily standups are held to discuss the current task status.

## Planning Process

- Tasks are broken down into user stories and estimated by completion time.
- Task priorities are set based on their importance to the overall project.
- Tasks are planned during sprint planning sessions and monitored during execution.
